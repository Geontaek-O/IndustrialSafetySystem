# AIoT 기반 스마트 안전모 및 작업자 안전 모니터링 시스템

> **AIoT-based Smart Safety Helmet & Worker Safety Monitoring System**
> 본 프로젝트는 산업 현장 작업자의 안전을 실시간으로 모니터링하고, 위험 상황 발생 시 즉각적인 구조 체계를 구축하기 위한 **AIoT 기반 스마트 안전모 및 통합 관제 플랫폼**입니다.

라즈베리 파이 피코 2 WH 기반의 하드웨어 노드, 작업자용 안드로이드 애플리케이션, 객체 탐지 및 자세 분석 인공지능 모델(YOLO), 그리고 실시간 관제 웹 서버를 통합하여 관리합니다.

---

## 시스템 아키텍처 및 파트별 주요 기능

### 1. Hardware (Raspberry Pi Pico 2 WH)

- **멀티코어 병렬 처리 구조:**
  - **Core 0:** 온습도(DHT22) 및 물리적 충격(아날로그 세라믹 피에조) 센서 데이터 실시간 수집 및 BLE 통신 전송 제어.
  - **Core 1:** I2S 마이크 모듈 전담 스레드를 독립 구동하여 오버플로우 없는 실시간 오디오 PCM 데이터 스트리밍 연동.
- **지능형 센싱 알고리즘:** 하드웨어 단의 아날로그 임계값(Threshold) 필터링 기법을 적용하여 불필요한 미세 노이즈를 차단하고 유효 충격 데이터만 선별 전송.

### 2. Android Application

- **CameraX 기반 안면 데이터 캡처:** `FaceGuideActivity` 인터페이스를 통해 작업자의 정면 안면 영상을 표준화된 규격으로 촬영하고, 이를 AI 얼굴 인식 파이프라인과 연동하여 현장 출입 인증 체계 구현.
- **실시간 위치 스트리밍 및 양방향 피드백:** 모니터링 서비스가 활성화되어 있는 동안 웹 서버와 지속적으로 통신하며 하이브리드 위치 데이터(GPS+PDR)를 실시간으로 업링크 스트리밍 채널로 전송.
- **지오펜싱(Geofencing) 가상 장벽 시스템:** 웹 서버 관제탑으로부터 실시간으로 전송되는 관리자 지정 '위험 구역 설정 데이터'를 수신하여, 해당 반경 진입 시 작업자 앱 화면 내에 즉각적인 위험 경고 알림.
- **백그라운드 BLE 지속성 아키텍처:** 포그라운드 서비스(`location|connectedDevice`) 환경에서 구동되며, `autoConnect` 옵션 및 SharedPreferences 기반 MAC 주소 다이렉트 연결 방식을 통해 앱 백그라운드 전환 및 프로세스 강제 종료 시에도 블루투스 연결을 자동으로 끈질기게 복구.
- **복합 실내외 측위 시스템:** 실외 환경에서는 고정밀 GPS 데이터를 수집하고, 신호 음영 지역 및 실내 공간 진입 시 스마트폰 내부 센서를 활용한 **PDR(보행자 추측 항법)** 알고리즘과 칼만 필터를 융합하여 작업자의 실시간 위치 추적 중단 현상을 극복.
- **생체 신호 및 위기 감지:** 헬스 커넥트(Health Connect) API 연동을 통한 작업자 실시간 심박수 수집, 안전모 센서로부터 전달받은 충격 신호, 마이크 수신 음성 키워드 분석을 통한 다중 응급 구조 요청 로직 구현.

### 3. AI (Computer Vision & YOLO)

- **안면 인식 비전 모델 (Face Recognition):** 앱 인터페이스(CameraX)로부터 수신된 안면 이미지 데이터를 기반으로 작업자 안면 분석 및 매칭 데이터베이스 연동. 이를 이용한 실시간 작업자 판별.
- **이상 자세 및 위험 행동 탐지 (Anomaly Posture Detection):** AIoT 카메라 스트림을 기반으로 현장 내 작업자의 **추락/떨어짐, 전도/쓰러짐** 등의 위험 자세 변화를 실시간으로 분석하여 중대재해 예방을 위한 행동 감지 알고리즘 적용.
- **커스텀 파인튜닝 가중치:** 현장 위험 요소 및 작업자 안전 장구 착용 여부를 실시간으로 판별하기 위해 커스텀 데이터셋으로 특화 학습된 인공지능 모델 탑재.

### 4. Web & Server (통합 관제 플랫폼)

- **실시간 데이터 동기화 및 다기능 웹 API:** 안드로이드 단말 및 하드웨어 노드와 밀접하게 바인딩된 RESTful API 엔드포인트들을 구축하여 생체 신호, 출입 관리 등 인터페이스 제공.
- **실시간 위치 관제 맵 대시보드:** 앱이 작동하는 동안 수신되는 위도/경도 좌표 정보를 웹 인터페이스의 실시간 지도 화면 위에 매핑하여 전체 작업자의 이동 경로 실시간 시각화.
- **동적 위험 구역(Danger Zone) 설정 및 피드백 프로토콜:** 관리자가 웹 지도 UI 상에서 특정 구역을 위험 지역으로 드래그 설정하면, 해당 공간의 기하학적 데이터(Spatial Data)를 실시간으로 추출하여 실시간 모니터링 중인 작업자들의 단말기(App)로 즉각 피드백 전송.
- **위험 상황 통합 관제 및 시각적 하이라이팅:** SOS 긴급 호출 API 수신, 작업자 심박수 임계치 초과, AI 비전 단의 추락/쓰러짐 탐지, 안전모 센서 충격 감지 발생 시 대시보드 내 해당 작업자 노드 시각적 강조 표시 수행.
